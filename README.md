# 🐄 Beef Fest

## 📌 Project Overview
**Beef Fest** is a web application designed for **Eid ul Adha animal booking and sales**. The platform allows users to browse available animals, view details, and conveniently book their desired animal online for Qurbani.

This project aims to simplify the traditional animal purchasing process by making it **digital, fast, and accessible from anywhere**.

---

## 🌐 Live URL
https://beef-fest.vercel.app/

---

## 🚀 Key Features
- 🐐 Browse a variety of animals available for Eid ul Adha  
- 📄 Detailed information for each animal (price, type, etc.)  
- 🛒 Easy booking system for purchasing animals  
- 🔔 Instant toast notifications for user actions  
- 🎨 Modern and responsive UI design  
- ⚡ Smooth animations for better user experience
